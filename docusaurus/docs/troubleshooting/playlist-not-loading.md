# Playlist is not loading

## Quick checks

- Check the M3U URL or the Xtream server URL, username and password with your provider.
- Make sure the source is set as the **Active source** in **IPTV Sources**.
- Try another network. Some providers block certain regions, networks or VPNs.
- Large playlists take longer on the first load. Wait a moment, then use **Settings → Account → Refresh Channel List**.
- If movies or series are missing, the playlist may not mark them as movies or series.

## Still not working?

Write to [livoiptv@gmail.com](mailto:livoiptv@gmail.com) with:

- the app version (**Settings → Version**)
- your device model
- the source type (M3U or Xtream Codes)
- the exact error text

Please do not send your playlist URL, username or password.
